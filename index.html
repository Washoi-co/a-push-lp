A-PUSH Method

各チャプターで覚えるフレーズは、たったひとつ。
その型を、動詞と場面だけ変えながら、先生と共に200〜300回声に出します。

What have you been working on?

We have been working on this project for two weeks.

How long have you been working with this client?

We have been working with this client for three years.

繰り返すうちに、考える前にわかる、出てくる。
大切なのは「理解」ではなく、圧倒的な「慣れ」。

なぜ、たったひとつのフレーズなのか

英語を話せない理由は、単語を知らないからでも、文法を知らないからでもありません。知っているのに、口が動かない。ほとんどの人はここで止まっています。

だから A-PUSH では、1チャプターで扱う型をひとつに絞ります。このチャプターなら「have been -ing（ずっと〜し続けている）」。これだけです。

型はひとつ。中身だけ入れかえる

We have been → working on → this project → for two weeks.

主語のあとに「have been」、そのあとに動詞、そのあとに対象、最後に「どれだけ続いているか」。この並びだけを、中身を変えながら繰り返します。

What have you been working on?

We have been working on this project for two weeks.

How long have you been working with this client?

We have been working with this client for three years.

How long have you been in charge of this account?

I have been in charge of this account since 2023.

200〜300回で、何が起きるか

最初は「We have been のあとは何だっけ」と考えます。50回でつまずきが減り、100回で文の頭が勝手に出て、200回を超えると考える前に口が動いています。

※変化の現れ方や必要な回数には個人差があります。一定の回数を繰り返すことで特定の状態に達することをお約束するものではありません。

このとき、3つのことが同時に起きています。

口と舌が覚える

スポーツのフォームと同じです。繰り返した動きは、意識しなくても出るようになります。

耳が覚える

自分の声は、自分の耳に入ります。話した回数だけ、聞き取りも鍛えられます。

イメージが結びつく

絵と一緒に練習するので、「日本語に訳してから理解する」という遠回りがなくなります。

先生と共に、が絶対条件

話して覚える学習には、大きな落とし穴があります。間違ったまま、形が固まってしまうことです。一度崩れた発音や語順は、独学では自分で気づけません。300回繰り返せば、間違いも300回定着します。

A-PUSH では、常にネイティブ講師が隣にいます。ズレた瞬間にその場で直るので、間違った形のまま定着することがありません。

01

手続き記憶で覚える

自転車は、何年ぶりでも乗れます。体で覚えたことは、忘れないからです。英語も、その覚え方ができます。

記憶には2種類あります。ひとつは宣言的記憶。知識として頭に置いておくもので、思い出そうとすれば思い出せますが、忘れることもあります。もうひとつが手続き記憶。自転車、泳ぎ方、箸の持ち方のように、体が覚えている動作です。

第二言語習得研究の Ullman は、学習が進むほど言葉の処理が宣言的記憶から手続き記憶へ移っていくと整理しました。単語帳で覚えた英語が会話で出てこないのは、まだ前者に留まっているからです。「えーと、あの単語は…」と思い出している間に、会話は次へ進んでしまう。

そして手続き記憶を作る方法は、ひとつしかありません。繰り返し、体を通すこと。自転車を本で学んでも乗れないのと同じです。

参考：Ullman, Declarative/Procedural Model

02

日本語を、挟まない

日本語を挟まず、英語を英語のまま扱う。英語で聞いて、英語のまま返す。この回路を最初から育てます。

日本の英語教育の多くは、日本語で説明して英語を教える間接教授法です。A-PUSH が採用しているのは、英語を英語のまま扱う直接教授法。19世紀末にヨーロッパで生まれ、いまも海外の語学学校で使われ続けている方式です。

ひとつのフレーズを繰り返し発音することで、口と舌の筋肉が正しい動きを記憶します。同時に大量の英語を聞くことで、耳がその響きを覚える。考えなくても音と口と脳が自動的にリンクする状態。これが本当の「英語を話せる」感覚です。

参考：Direct Method（直接教授法）

03

むずかしく勉強しすぎている

TOEICのスコアは高いのに、いざとなると話せない。それは「難しい英語」から手をつけてしまっているからです。

難しい会話には、高度な論理的思考力が求められます。ただでさえ「英語を処理する」こと自体に脳のエネルギーを奪われている状態で、さらに難しい論理思考までやろうとすれば、脳はキャパシティオーバーを起こしてフリーズします。

やさしい表現に徹底的に慣れ、何も考えなくても処理できるようにする。すると英語の処理にかかる負担がゼロに近づき、論理的な思考に脳のエネルギーを100%使えるようになります。だから A-PUSH は、まず「簡単な表現」を無意識レベルで完璧に処理できる回路を鍛え上げます。

参考：Cummins, BICS & CALP

FOUNDER

英語は、“話さないから話せない”

FOUNDER

佐野 公章KIMIAKI SANO

米国テンプル大学 日本校 所属

17歳、フィリピンに語学留学。
"Slow please."と頼んでも、
何を言っているかわからなかった。

高校2年の2月、セブ島の語学学校に短期留学。中学からずっと英語をやってきて、文法は解ける、長文も読める、テストの点数も悪くはなかった。だから正直、少しは通じるだろうと思っていました。

通じませんでした。何度も聞き返して、それでも分からなくて「Slow please.」とお願いする。それでも分からない。相手が困った顔をするのが、一番つらかった。

滞在は6週間。普通より速いペースで英語を浴びて、そのまま真似して口に出す。同じ型を何度も繰り返す学習法に出会い、2週間ほど経った頃、はっきりと変化がありました。英語が、ゆっくり聞こえるんです。相手の話す速度は変わっていません。変わったのは、自分のほうでした。

繰り返すうちに分かったのは、英語の「音」をそもそも知らなかったということ。口が音をつくれるようになると、耳がその音を拾えるようになる。話す練習が、そのまま聞く力になっていました。

音がわかってからは早かった。英語を「考えなくてよくなった」からです。話すときに文法を組み立てない、聞くときに日本語に訳さない。その2つがなくなるだけで、会話はまったく別物になりました。

17歳の私がフィリピンで受け取ったものを、日本でも渡せるようにする。それが A-PUSH をつくった理由です。

出典：Ullman, Declarative/Procedural Model（手続き記憶）／ Cummins, BICS & CALP

FAQ

よくある質問

英語が全くの初心者でも大丈夫ですか？

大丈夫です。A-PUSH はまず BICS（生活での基礎英語）から鍛える設計なので、難しい文法や語彙の知識は前提にしていません。足りない部分は「話しながら埋める」進め方になります。

仕事が忙しくても続けられますか？

オンラインで受講でき、毎日の課題も公式LINEで届くため、移動中や在宅の日でも進められます。何をやるかはこちらが決めてお渡しするので、「メニューを考える時間」は必要ありません。

マンツーマン以外の形式はありますか？

現在はマンツーマンのみです。話す時間がそのままレッスン時間になるため、スピーキングを伸ばす目的では最も効率が高い形式だと考えています。

返金は可能ですか？

返金ではなく、受講期間の1ヶ月無償延長という形での保証をご用意しています。学習進捗の提出80%以上・レッスン出席率80%以上を満たしていただいたうえで、所定のテストで成績が伸びなかった場合が対象です（3ヶ月以上のプラン）。

どのくらいの期間で話せるようになりますか？

到達度には個人差がありますが、A-PUSH は3ヶ月を一区切りとして設計しています。具体的な目標と現在地は、体験会でお伝えします。
